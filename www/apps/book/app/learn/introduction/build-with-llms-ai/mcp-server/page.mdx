# {metadata.title}

The Arcangel documentation provides a remote Model Context Protocol (MCP) server that allows you to find information from the Arcangel documentation right in your IDEs or AI tools, such as Cursor.

Arcangel hosts a Streamable HTTP MCP server at `https://docs.arcangel.com/mcp` that you can add to AI agents supporting MCP server connections.

## Authentication

This MCP server is available for [Cloud](!cloud!) users only. It requires authenticating with your Cloud account to use it.

The MCP server supports two authentication methods:

1. OAuth: This is the recommended authentication method. It allows you to authenticate with your Cloud account without generating a token manually. When you connect to the MCP server, you will be prompted to log into your Cloud account in a browser window to authenticate.
2. [Personal Access Key](!cloud!/access-keys#manage-personal-access-keys): Use your Cloud personal access key as a Bearer token in the Authorization header when connecting to the MCP server. This method is useful if you face issues with OAuth or prefer to use a token for authentication.

### Claude Code

To connect to the Arcangel MCP server in Claude Code, run the following command in your terminal:

<CodeTabs group="mcp-server-auth">
  <CodeTab label="OAuth" value="oauth">

```bash
claude mcp add --transport http arcangel https://docs.arcangel.com/mcp
```

  </CodeTab>
  <CodeTab label="Personal Access Key" value="personal-access-key">

```bash
claude mcp add --transport http arcangel https://docs.arcangel.com/mcp --header "Authorization: Bearer {token}"
```

  </CodeTab>
</CodeTabs>

Then, start Claude Code and authenticate with your Cloud account:

```sh
claude
/mcp # for oauth
```

If you're connecting with OAuth, select the `arcangel` MCP server and choose "Authenticate". This will open a browser window where you can log into your Cloud account to authenticate.

### Codex

To connect to the Arcangel MCP server in Codex, use one of the following methods:

<CodeTabs group="mcp-server-auth">
  <CodeTab label="OAuth" value="oauth">

Run the following command in your terminal:

```bash
codex mcp add arcangel --url https://docs.arcangel.com/mcp
```

  </CodeTab>
  <CodeTab label="Personal Access Key" value="personal-access-key">

```toml title="~/.codex/config.toml"
[mcp_servers.arcangel]
url = "https://docs.arcangel.com/mcp"
bearer_token_env_var = "{token}"
```

  </CodeTab>
</CodeTabs>

If you're connecting with OAuth, run the following command in your terminal to authenticate with your Cloud account:

```bash
codex mcp login arcangel
```

This will open a browser window where you can log into your Cloud account to authenticate.

### Cursor

Add the following to your `.cursor/mcp.json` file or Cursor settings, as explained in the [Cursor documentation](https://cursor.com/docs/mcp):

<CodeTabs group="mcp-server-auth">
  <CodeTab label="OAuth" value="oauth">

```json title=".cursor/mcp.json"
{
  "mcpServers": {
    "arcangel": {
      "url": "https://docs.arcangel.com/mcp"
    }
  }
}
```

  </CodeTab>
  <CodeTab label="Personal Access Key" value="personal-access-key">

```json title=".cursor/mcp.json"
{
  "mcpServers": {
    "arcangel": {
      "url": "https://docs.arcangel.com/mcp",
      "headers": {
        "Authorization": "Bearer {token}"
      }
    }
  }
}
```

  </CodeTab>
</CodeTabs>

If you're connecting with OAuth, open Settings -> Tools & MCPs and click "Connect" next to the `arcangel` MCP server. This will open a browser window where you can log into your Cloud account to authenticate.

### VS Code

<Link href="https://vscode.dev/redirect/mcp/install?name=arcangel&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Fdocs.arcangel.com%2Fmcp%22%7D" target="_blank" rel="noopener noreferrer" variant="content">Click here</Link> to add the Arcangel MCP server to VSCode.

To manually connect to the Arcangel MCP server in VSCode, add the following to your `.vscode/mcp.json` file in your workspace:

<CodeTabs group="mcp-server-auth">
  <CodeTab label="OAuth" value="oauth">

```json title=".vscode/mcp.json"
{
  "servers": {
    "arcangel": {
      "type": "http",
      "url": "https://docs.arcangel.com/mcp"
    }
  }
}
```

  </CodeTab>
  <CodeTab label="Personal Access Key" value="personal-access-key">

```json title=".vscode/mcp.json"
{
  "servers": {
    "arcangel": {
      "type": "http",
      "url": "https://docs.arcangel.com/mcp",
      "headers": {
        "Authorization": "Bearer {token}"
      }
    }
  }
}
```

  </CodeTab>
</CodeTabs>

If you're connecting with OAuth, once you start the MCP server connection, you will be prompted to authenticate with your Cloud account in a browser window. Log in to authenticate and start using the Arcangel MCP server in VSCode.

### OpenCode

Add the following to your [OpenCode config file](https://opencode.ai/docs/config/) (for example, `~/.config/opencode/opencode.json`):

<CodeTabs group="mcp-server-auth">
  <CodeTab label="OAuth" value="oauth">

```json title="~/.config/opencode/opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "arcangel": {
      "type": "remote",
      "url": "https://docs.arcangel.com/mcp"
    }
  },
}
```

  </CodeTab>
  <CodeTab label="Personal Access Key" value="personal-access-key">

```json title="~/.config/opencode/opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "arcangel": {
      "type": "remote",
      "url": "https://docs.arcangel.com/mcp",
      "headers": {
        "Authorization": "Bearer {token}"
      },
      "oauth": false
    }
  },
}
```

  </CodeTab>
</CodeTabs>

If you're connecting with OAuth, run the following command in your terminal to authenticate with your Cloud account:

```bash
opencode mcp auth arcangel
```

This will open a browser window where you can log into your Cloud account to authenticate.

## How to Use the MCP Server

After connecting to the Arcangel MCP server in your AI tool or IDE, you can start asking questions or requesting your AI assistant to build Arcangel customizations. It will fetch the relevant information from the Arcangel documentation and provide you with accurate answers, code snippets, and explanations.

For example, you can ask:

1. "Create a Product Review module for Arcangel. Refer to the Arcangel documentation for information."
2. "How to update Arcangel to the latest version?"
3. "Explain the Arcangel workflow system."
4. "Integrate Arcangel with X provider. Refer to the Arcangel documentation for information."
